Technical Note: In our definition, the inverse function f −1 is only required to be defined on
the range of f . With this convention there is no need for f to be surjective or “onto” to have an
inverse. This may conflict with conventions you may be learning in other classes.
Horizontal Line Test: A function is one-to-one if and only if every horizontal line intersects
the graph of f at most once.
If a function is not one-to-one, shrinking the domain may allow us to find an inverse to a part
of a function (used later in section 7.5 extensively). For instance, although f (x) = 3(x + 1)−2 is
not one-to-one on its domain x 6 = −1, it is one-to-one when restricted to the interval (−1, ∞)
(or to the interval (−∞, −1)). Thus, an inverse exists for f on the domain x > −1.
